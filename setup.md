Download the "csc_analyst.py" file or copy raw to a notepad file and save as a .py 

Open the application ## Note wherever you open the file a folder named "csc_workplace" will get populated here and 
all downloaded demos will go to this location if you would like them to go to a different location you can fix this with 
``` set DEMO_DIR D:\your\folder\here ```

type home to bring up the the home menu again 

type 1 and type in the CSC team name NOT the org name if you don't know how to spell it or are having a hard time type 19 and select the number next to the team

type home then type 2 ## this will download all the CURRENT season demos 

type 4 then hit enter and let it parse

from here you can do anything you'd like with the parsed data however if you want the report just type 10 and hit enter

20 is how you control its style
