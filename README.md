# CSC-Jabich
CSC Analyst tool to generate a report on teams that include heatmaps and anti-strat suggestions based on raw demo information
The tool has both a generate report function to show you absolutely everything on a team but if you want more specific info or more tuned search queries 
you also have a terminal that is rather user friendly once you understand the syntax to deep query statistics the terminal portion functions like MSFconsole with 
option variables ie "set PLAYER xDiedrich" can be ran anywhere in the session and remain persistent for future uses in that session more can be seen in the syntax page for this.
